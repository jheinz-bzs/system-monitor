# What's New

## System Monitor

Thanks for updating. Here's what changed recently.

### Session recording
- Record a monitoring session to a CSV file with the new record toggle in the
  **status bar** — pick where to save, and one row per second captures CPU,
  memory, swap, network, disk I/O, and process count until you stop.
- Recording is off by default and never starts on its own; nothing is written
  unless you start a session.

### Recordings tab
- Open a saved recording in the new **Recordings** tab and browse it as charts.
- Hover over a chart to see the exact value and time of any sample.
- The CPU chart shades the stretches where usage sat above your alert
  threshold, so the hot spots stand out at a glance.
