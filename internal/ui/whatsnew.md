# What's New

## System Monitor

Thanks for updating. Here's what changed recently.

### Fixes
- On Windows, the app's **Start Menu** shortcut now repairs itself if the app
  was moved or renamed — launching from Start or Windows search keeps working,
  and alert notifications keep showing **System Monitor** as the sender.
- Install paths containing an apostrophe (like `O'Brien`) no longer break the
  shortcut setup.
